# Jaro Brichau — portfolio rebuild

Rebuild of [jarobrichau.be](https://jarobrichau.be/) closely modelled on [tomdekoning.work](https://www.tomdekoning.work/).

**Positioning:** all-round digital creative · Digital Marketing Consultant at [DIDIOM](https://didiom.be/).

## Run

```bash
cd app
npm install
npm run dev
```

## Sections

`#header` · `#info` · `#about` · `#work` · `#contact` (hash nav + menu overlay, same IA as TDK)

## Stack

Vite · React · TypeScript · GSAP · Lenis
