# Jaro Brichau — portfolio rebuild

Mix of [tomdekoning.work](https://www.tomdekoning.work/) visual system + multi-page structure inspired by the old [jarobrichau.be](https://jarobrichau.be/) portfolio.

**Positioning:** all-round digital creative · Digital Marketing Consultant at [DIDIOM](https://didiom.be/).

## Run

```bash
cd app
npm install
npm run dev
```

## Pages

- `/` Home (TDK-style hero + info + about tease + work)
- `/work` Work index
- `/work/:slug` Case studies (brief / insight / idea / impact)
- `/about` Story, skills, timeline
- `/contact` Contact

## Stack

Vite · React · React Router · TypeScript · GSAP · Lenis
